CORE ASSURANCES

The Four Security Pillars

Technically verified protections ensuring enterprise compliance and sovereign document sanctity.

🔐

ENCRYPTION

Data protected during transmission via TLS 1.3 and at rest using envelope encryption with AES-256 GCM.

🛡️

ACCESS CONTROL

Role-based access controls all sensitive operations. Zero cross-tenant data leakage by design.

📋

AUDITABILITY

Sensitive actions are recorded in immutable, append-only audit ledgers with correlation IDs and IP binding.

🔎

VERIFICATION

Evidence and trusted sovereign sources (GSTN, MCA, CBDT, NSDL) are used for cryptographic cross-examination.

AI GOVERNANCE DOCTRINE

AI ASSISTS — HUMANS DECIDE

Veripass rejects unchecked algorithmic governance. Machine learning accelerates evidence ingestion, but licensed compliance officers sign off on every legal outcome.

What AI Does:

  • ✓ High-speed OCR extraction across complex document formats
  • ✓ Data normalization across disparate state tax schemas
  • ✓ Anomaly detection and tampering pattern analysis
  • ✓ Synthesizing multi-source composite risk signals

What AI Never Does:

  • ✕ Automatically approve a supplier without human oversight
  • ✕ Automatically reject or revoke a verified business identity
  • ✕ Make unilateral, irreversible verification decisions
  • ✕ Hide the evidence chain behind an unexplainable "black box"
